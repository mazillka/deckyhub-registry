Catalog

Exactly what DeckyHub shows on Discover, loaded live from registry/apps.json. Plugins are suggested by users or found through Decky Extended Plugins and Decky Plugins Explorer, and each is checked for a working release before it's added.

Runs as root The plugin asks Decky Loader to run its backend as the root user, which can read and change anything on the Deck, including system files, other plugins and your data. Many plugins need it for real reasons (fan or power control, drivers, VPNs, system settings), so it isn't a warning sign on its own. It does mean a bug or a malicious update can do far more harm, so install these only from authors you trust. No release in a year The newest release is over a year old, so it may not work with current SteamOS or Decky Loader.

Contribute

A merged change reaches every DeckyHub on its next restart. No app update needed.

Suggest a plugin

Know a Decky plugin that belongs here? Open an issue with its repository.

Add it yourself

Add an entry to registry/apps.json and its row in the README, then open a pull request. CI checks it against the plugin's real releases. How-to

Run your own list

Fork this repository and add it in DeckyHub under Repositories → Custom Registries as owner/repo.

Registry editor

Prefer a bigger screen? Build or edit a plugin list in your browser and export it as a registry file. Host it anywhere over HTTPS (a GitHub repo works) and add it in DeckyHub under Settings → Repositories → Custom Registries. Nothing is uploaded. Open the editor
