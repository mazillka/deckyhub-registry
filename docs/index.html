Catalog

Exactly what DeckyHub shows on Discover, loaded live from registry/apps.json. Plugins are suggested by users or found through Decky Extended Plugins and Decky Plugins Explorer, and each is checked for a working release before it's added.

Runs as root The plugin asks Decky Loader to run its backend as the root user, which can read and change anything on the Deck, including system files, other plugins and your data. Many plugins need it for real reasons (fan or power control, drivers, VPNs, system settings), so it isn't a warning sign on its own. It does mean a bug or a malicious update can do far more harm, so install these only from authors you trust. No release in a year The newest release is over a year old, so it may not work with current SteamOS or Decky Loader. Fork A fork that carries a plugin on after its original stopped (hover it for the original); listed only while it's the active one. AI Its repository has instructions for AI coding assistants (such as CLAUDE.md, AGENTS.md, .cursorrules or .github/copilot-instructions.md), so it's likely developed with AI help (hover it for which). That says nothing about its quality or safety either way, and no badge doesn't mean no AI was used.

Warnings come from Decky Extended Plugins' automated audit of the release DeckyHub installs (or a newer pre-release, marked as such). Routine findings like sudo, mount or systemctl, which many plugins need on SteamOS, aren't shown. A warning isn't proof of harm and no warning isn't proof of safety, so check the repository. Blocked by audit The audit found malware or a broken archive. Not recommended for installation. Reads private data Its code reads Steam login data, SSH keys or secrets from the environment. Changes system startup It edits shell profiles, preloads libraries, loads kernel modules or adds device rules, which keep working outside Decky. Code not in its repo The release ZIP has scripts or programs that aren't in its GitHub source, so you can't read what they do. Hidden code It contains encoded or packed code that's hard to read. Skips HTTPS checks It turns off certificate checks, so what it downloads could be tampered with. Runs downloaded scripts It downloads a script and runs it straight away. Known vulnerabilities It bundles libraries with published security flaws.

Every plugin ZIP DeckyHub can install is virus-scanned every few hours: with ClamAV, an open-source antivirus, and the files inside it with YARA and YARA Forge's community rules, many of them written for Linux malware. The badge is for the release DeckyHub installs by default (the newest stable one), or a newer pre-release, marked as such. Hover it for each scanner's result, the file and when it was scanned; a plugin without one hasn't been scanned yet. In DeckyHub, a plugin's Manage window has the full report and can look the file up on VirusTotal. A clean scan isn't proof of safety, and a match can be a false positive. No threats Neither scanner found anything. Threat found ClamAV matched known malware, or a YARA rule written to catch it matched. Check the repository before installing. Not fully scanned A scanner couldn't look at all of it: the ZIP went past its size limits, some files couldn't be read, or the scan failed. Hover it for why; it's scanned again on the next run.

Contribute

Changes land on develop first, then ship to main, which reaches every DeckyHub on its next restart. No app update needed.

Suggest a plugin

Know a Decky plugin that belongs here? Open an issue with its repository.

Add it yourself

Add an entry to registry/apps.json and its row in the README, then open a pull request. CI checks it against the plugin's real releases. How-to

Run your own list

Fork this repository and add it in DeckyHub under Settings → Repositories → Custom Registries as owner/repo.

Registry editor

Prefer a bigger screen? Build or edit a plugin list in your browser and export it as a registry file. Host it anywhere over HTTPS (a GitHub repo works) and add it in DeckyHub under Settings → Repositories → Custom Registries. Nothing is uploaded. Open the editor

Install at your own risk. DeckyHub only fetches releases from their authors' GitHub repositories. It doesn't make, review or vouch for these plugins and isn't responsible for anything they do to your device or data.
